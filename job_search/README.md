# Mirra Job — ассистент поиска работы (Россия)

Собственный Python-ассистент на API RouterAI/DeepSeek + открытое API hh.ru.
Вдохновлён `MadsLorentzen/ai-job-search`, но переписан под наш стек:
без Claude Code, без датских порталов, без обязательного LaTeX.

## Возможности

- **search** — поиск вакансий на hh.ru по ключевым словам.
- **evaluate** — оценка соответствия профиля конкретной вакансии (fit + пробелы).
- **apply** — полный отклик: черновик cover letter + CV → ревьюер-агент → правки → финал.

## Источник данных

Профиль читается из `profile/*.md` (только профессиональные файлы, список в `config.py`).
Личные темы (отношения, финансы, здоровье) в отклик НЕ попадают.

## Запуск

### macOS — одним кликом

Двойной клик по файлу **`MirraJob.command`** (в корне проекта).
Откроется Терминал, запустится сервер, браузер сам откроет страницу
`http://localhost:8765`.

Чтобы остановить — закрой окно Терминала или нажми `Ctrl+C`.

> Если macOS впервые спрашивает разрешение — это потому что `.command`
> исполняемый. Разреши запуск в Терминале.

### Вручную (любая ОС)

```bash
cd job_search
python3 server.py
# затем открой http://localhost:8765
```

### CLI-режим (без браузера)

```bash
cd job_search

# поиск вакансий (СПб по умолчанию)
python main.py search "QA lead"
python main.py search "QA lead" --area 1      # Москва
python main.py search "QA lead" --area 113    # вся Россия

# оценить вакансию по id с hh.ru
python main.py evaluate 123456789

# полный отклик
python main.py apply 123456789
python main.py apply --text "вставь сюда текст вакансии"
```

Результат CLI сохраняется в `job_search/output/`:
- `cover_letter_draft.md`, `cv_draft.md` — черновики;
- `review.md` — замечания ревьюера;
- `final.md` — финальная версия (cover letter + CV).

## Зависимости

Только стандартная библиотека Python 3.10+. Ничего ставить не нужно.

## Конфиг

Всё в `config.py`: ключ RouterAI, модель, регион hh.ru, список файлов профиля, промпты.

> ⚠️ Ключ RouterAI хранится в `config.py` открыто. Если захочешь закоммитить проект —
> вынеси ключ в переменную окружения `ROUTERAI_KEY` и убери его из файла.
